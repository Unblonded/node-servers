Clones it into , installs its packages and starts it. Or put a folder there yourself: it's picked up within a few seconds.

    

  




  

    
settings.json

    
    

      checkEverySeconds between checks for new commits (at least 15).
      dashboardPortThis dashboard's port (applies when the supervisor next starts).
      deploymentWhere the servers are, if not ..\deployment (applies when the supervisor next starts).
      servers.<folder>.startThe command that starts it, instead of what's detected.
      servers.<folder>.updatefalse to never update it, or a command to update it with.
      servers.<folder>.envExtra environment variables, like { "PORT": "3300" }.
      servers.<folder>.healthA port or URL to check every 30s; three misses in a row restart it.
      servers.<folder>.enabledfalse to leave it off.
